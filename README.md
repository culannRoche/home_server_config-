# Home Server Project

This project documents my home server setup in order to make it easier to setup a standard environment I can re-use across different devices.
The project is based on a Debian base with Docker containers to separate services.

bootstrap.sh will provide the basic setup for the docker containers.
There will be indivdual setup scripts for each docker container I add to my servers, which I will post here as well.

If you find any bugs or would like to suggest some changes to improve my scripts, please feel free to make a suggestion.
